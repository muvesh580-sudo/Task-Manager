# 📝 Task Manager

A modern, responsive task management web app built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

**Vercel:** https://task-manager-snowy-seven-96.vercel.app/

**GitHub Pages:** https://muvesh580-sudo.github.io/Task-Manager/

## ✨ Features

- ✅ Add tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✔️ Complete / Undo tasks
- 🔍 Search tasks
- 🗂️ Filter by All, Active, and Completed
- 📊 Total and completed task counters
- ⭐ Task priorities — Low, Medium, High
- 🏷️ Task categories — Study, Work, Personal, Other
- 📅 Due dates
- 🔴 Overdue task detection
- 💾 Persistent data using Local Storage
- 🌙 Dark mode
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- Responsive Design
